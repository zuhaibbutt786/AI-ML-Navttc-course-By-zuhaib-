Boosting — Closing Classical ML

Hour 2–4 · From weak learners to strong ensembles (Tasks 56–64)

Why Boosting Before Neural Nets? Hour 2

Last week you used a single Decision Tree and a Random Forest. Boosting is another ensemble idea: instead of averaging independent trees, you train them sequentially, each new tree focusing on the mistakes of the previous ones. The result is often the strongest “out-of-the-box” model on tabular data — and still dominates many Kaggle competitions alongside neural nets.

Three names you will meet in industry:

  • AdaBoost — reweights hard examples; historically important
  • Gradient Boosting — each tree fits the residual (negative gradient) of the loss
  • XGBoost / LightGBM / CatBoost — highly optimized gradient boosting libraries used in production

Video: “Gradient Boosting — Clearly Explained” — StatQuest

Gradient Boosting in One Picture Hour 2–3

Start with a simple model F₀ (e.g. predict the mean)
For m = 1 … M:
    1. Compute residuals  rᵢ = yᵢ − Fₘ₋₁(xᵢ)     # what the current model still gets wrong
    2. Fit a small tree hₘ to the residuals
    3. Update:  Fₘ = Fₘ₋₁ + η · hₘ               # η = learning rate (shrinkage)
Final prediction = F_M(x)

The learning rate η keeps each step small so the ensemble generalizes better. Typical values: 0.01 – 0.3. More trees + smaller η is usually safer than few trees + large η.

MLP — Feed-Forward Neural Networks

Hour 1–4 · Forward pass, activations, loss, backpropagation, regularization

From Logistic Regression to a Neural Network Hour 1

Logistic Regression (Week 5) is a single neuron: weighted sum → sigmoid → probability. A Multilayer Perceptron (MLP) stacks many such neurons in layers. Hidden layers learn intermediate representations; the output layer produces the final prediction.

Input layer   →  Hidden layer(s)  →  Output layer
  x₁, x₂, …        z = g(Wx + b)       ŷ = softmax(…)  or  sigmoid(…)
                   g = activation

Each connection has a weight. Training means adjusting all weights so the network’s predictions match the labels — exactly the same “guess → measure error → update” loop you already know from gradient descent, just with far more parameters.

Video: “But what is a neural network?” — 3Blue1Brown (highly recommended)

Forward Pass & Activation Functions Hour 1–2

The forward pass computes the output from the input by matrix multiplies and non-linear activations at each layer:

z¹ = W¹x + b¹
a¹ = g(z¹)          # hidden activation
z² = W²a¹ + b²
ŷ  = g_out(z²)      # output (sigmoid / softmax / linear)

Without a non-linearity g, stacking layers collapses to one big linear model. Common activations:

FunctionFormulaTypical use
ReLUmax(0, z)Default for hidden layers
Sigmoid1 / (1 + e⁻ᶻ)Binary output, gates
Tanh(eᶻ − e⁻ᶻ) / (eᶻ + e⁻ᶻ)Hidden layers (older nets)
Softmaxeᶻᵢ / Σ eᶻⱼMulti-class output
Leaky ReLUmax(αz, z)Avoids “dead” ReLUs
 
import numpy as np

def relu(z):
    return np.maximum(0, z)

def sigmoid(z):
    return 1 / (1 + np.exp(-np.clip(z, -500, 500)))

def softmax(z):
    e = np.exp(z - z.max(axis=-1, keepdims=True))  # stable
    return e / e.sum(axis=-1, keepdims=True)

Loss: Cross-Entropy Hour 2

For classification we almost always use cross-entropy loss (the same idea behind logistic regression’s cost function, generalized to many classes):

Binary:     L = −[ y log ŷ + (1−y) log(1−ŷ) ]
Multi-class: L = − Σₖ yₖ log ŷₖ     (y one-hot)

Cross-entropy + softmax has a clean gradient and pushes probability mass onto the correct class.

Computational Graph & Backpropagation Hour 2–3

Backpropagation is just the chain rule applied systematically from the loss back to every weight. Modern frameworks build a computational graph during the forward pass and then walk it backwards to compute gradients automatically (autograd / automatic differentiation).

Forward:  store intermediate activations
Backward: δ_output = ŷ − y                         # for softmax + CE
          δ_hidden = (W²ᵀ δ_output) ⊙ g'(z¹)
          ∂L/∂W² = a¹ᵀ δ_output
          ∂L/∂W¹ = xᵀ δ_hidden
Then: W ← W − η · ∂L/∂W
Intuition Each weight is blamed in proportion to how much it contributed to the final error. That “blame signal” is exactly the gradient. 3Blue1Brown’s calculus series on backprop is the clearest visual explanation available.

Video: “What is backpropagation really doing?” — 3Blue1Brown

Vanishing & Exploding Gradients Hour 3

In deep networks the gradient can shrink toward zero (vanishing) or blow up (exploding) as it is multiplied through many layers. Symptoms: training stalls, or weights become NaN.

  • Causes: sigmoid/tanh in deep stacks, poor weight initialization, very deep nets
  • Fixes: ReLU activations, careful init (He / Xavier), residual connections (later), gradient clipping, batch normalization

Overfitting, Underfitting & Dropout Hour 4

Neural nets are high-capacity models — they memorize training data easily.

  • Underfitting: both train and test error high → bigger model, train longer, better features
  • Overfitting: train error low, test error high → more data, regularization, early stopping

Dropout randomly sets a fraction of activations to zero during training (typical rate 0.2–0.5). At test time all units are used (scaled). It forces the network not to rely on any single neuron — a powerful regularizer.

# conceptual dropout during training
mask = (np.random.rand(*a.shape) > drop_rate) / (1 - drop_rate)
a_dropped = a * mask
Remember Dropout is active only at training time. Frameworks handle the train/eval switch for you when you call model.train() / model.eval() (PyTorch) or when using the right mode in Keras.

First MLP in Keras Hour 1–2

import tensorflow as tf
from tensorflow import keras
from tensorflow.keras import layers

# Example: binary classification on a feature matrix X (n_samples, n_features)
model = keras.Sequential([
    layers.Input(shape=(X_train.shape[1],)),
    layers.Dense(64, activation='relu'),
    layers.Dropout(0.3),
    layers.Dense(32, activation='relu'),
    layers.Dense(1, activation='sigmoid')
])

model.compile(
    optimizer=keras.optimizers.Adam(learning_rate=1e-3),
    loss='binary_crossentropy',
    metrics=['accuracy', keras.metrics.AUC(name='auc')]
)

history = model.fit(
    X_train, y_train,
    validation_split=0.2,
    epochs=30,
    batch_size=32,
    callbacks=[
        keras.callbacks.EarlyStopping(patience=5, restore_best_weights=True)
    ]
)

model.evaluate(X_test, y_test)

Same Idea in PyTorch Hour 2–3

import torch
import torch.nn as nn
from torch.utils.data import DataLoader, TensorDataset

class MLP(nn.Module):
    def __init__(self, n_in):
        super().__init__()
        self.net = nn.Sequential(
            nn.Linear(n_in, 64),
            nn.ReLU(),
            nn.Dropout(0.3),
            nn.Linear(64, 32),
            nn.ReLU(),
            nn.Linear(32, 1)
        )
    def forward(self, x):
        return self.net(x).squeeze(-1)

model = MLP(X_train.shape[1])
opt = torch.optim.Adam(model.parameters(), lr=1e-3)
loss_fn = nn.BCEWithLogitsLoss()

X_t = torch.tensor(X_train, dtype=torch.float32)
y_t = torch.tensor(y_train, dtype=torch.float32)
loader = DataLoader(TensorDataset(X_t, y_t), batch_size=32, shuffle=True)

model.train()
for epoch in range(30):
    for xb, yb in loader:
        opt.zero_grad()
        loss = loss_fn(model(xb), yb)
        loss.backward()
        opt.step()

Training Hygiene Checklist Hour 3–4

  • Scale inputs (StandardScaler / MinMax) — neural nets are sensitive to feature scale
  • Use a validation set or validation_split; monitor val_loss
  • EarlyStopping to avoid overfitting
  • Start with Adam and lr ≈ 1e-3; adjust if loss explodes or plateaus
  • Batch size 32–256 is a solid default on CPU/GPU
  • Plot train vs val curves — the most important debugging tool
import matplotlib.pyplot as plt
plt.plot(history.history['loss'], label='train')
plt.plot(history.history['val_loss'], label='val')
plt.legend(); plt.xlabel('epoch'); plt.ylabel('loss')
plt.title('Learning curves')

Convolutional Neural Networks (CNNs)

Hour 1–4 · Spatial filters for images and sequences for text

Why Convolutions? Hour 1

A fully connected layer on a 224×224 RGB image would need tens of millions of weights just for the first layer — and would ignore the fact that nearby pixels are related. Convolution slides small learnable filters across the image, detecting local patterns (edges, textures, then parts, then objects) with far fewer parameters and translation equivariance.

Input image
  → Conv + ReLU + (optional Pool)   # low-level features
  → Conv + ReLU + Pool              # mid-level
  → …
  → Flatten / GlobalAveragePool
  → Dense → Softmax                 # class scores

Video: Convolutional Neural Networks explained (intuitive walkthrough)

2D CNN for Image Classification Hour 1–2

from tensorflow.keras import layers, models

model = models.Sequential([
    layers.Input(shape=(28, 28, 1)),          # e.g. MNIST
    layers.Conv2D(32, 3, activation='relu'),
    layers.MaxPooling2D(2),
    layers.Conv2D(64, 3, activation='relu'),
    layers.MaxPooling2D(2),
    layers.Flatten(),
    layers.Dense(64, activation='relu'),
    layers.Dropout(0.4),
    layers.Dense(10, activation='softmax')
])

model.compile(optimizer='adam',
              loss='sparse_categorical_crossentropy',
              metrics=['accuracy'])

# history = model.fit(x_train, y_train, epochs=5, validation_split=0.1)

Key layer ideas:

  • Conv2D(filters, kernel_size) — learnable filters
  • MaxPooling2D — downsample, keep strongest response
  • Flatten or GlobalAveragePooling2D — connect to dense head

1D CNN for Text / Sequences Hour 3–4

The same idea works on sequences: slide filters over token embeddings to detect local n-gram patterns. 1D CNNs are fast and strong baselines for text classification before you move to RNNs / Transformers (Weeks 8–9).

vocab_size = 10000
max_len = 200
embed_dim = 64

text_model = models.Sequential([
    layers.Embedding(vocab_size, embed_dim, input_length=max_len),
    layers.Conv1D(128, 5, activation='relu'),
    layers.GlobalMaxPooling1D(),
    layers.Dense(64, activation='relu'),
    layers.Dense(1, activation='sigmoid')
])

text_model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
# text_model.fit(x_train_seq, y_train, epochs=5, validation_split=0.2)
Industry note CNNs still power many vision systems (with ResNet, EfficientNet, etc.). For pure text, Transformers dominate benchmarks, but 1D CNNs remain useful when you need speed and a simple pipeline on moderate data.

Debugging Playbook

  • Loss is NaN → lower learning rate, clip gradients, check for log(0)
  • Loss flat from epoch 1 → learning rate too small, or labels/features wrong scale
  • Train acc ≫ val acc → more dropout, more data, simpler model, early stop
  • Both acc low → undercapacity or undertraining; train longer / wider net

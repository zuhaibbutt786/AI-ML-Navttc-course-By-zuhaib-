AI Orientation, Career Landscape & Environment Setup

Introduction to Artificial Intelligence Hour 1

Lesson overview. AI is software that performs tasks which normally require human judgment — recognizing a face, translating a sentence, recommending a video, driving a car. Machine Learning (ML) is the dominant way we build AI today: instead of hand-writing rules, we show a program examples and let it find the pattern. Deep Learning (DL) is a family of ML techniques built on layered neural networks, responsible for the recent wave of breakthroughs in vision, speech, and language.

Why companies use it. AI turns data a company already collects — clicks, transactions, sensor readings, support tickets — into decisions: what to recommend, what's fraud, what a scan shows, what a customer will say next. That converts fixed data-storage cost into ongoing product value, which is why every major tech budget now has an AI line item.

Additional Industry Knowledge The three terms nest inside each other: AI is the goal (machines behaving intelligently), ML is one strategy for reaching it (learning from data), and DL is one family of ML techniques (deep neural networks). Not all AI is ML — a chess engine using hand-coded rules is AI but not ML. Not all ML is DL — a spreadsheet-style linear regression is ML but not deep.

Interview importance. "Explain the difference between AI, ML, and DL in plain language" is one of the most common opening interview questions in this field, because it tests whether a candidate actually understands the landscape or just memorized buzzwords.

Linux Shell Scripting Fundamentals

Hour 1–4 · Debian basics · File commands · System control · Environment variables

Introduction to Debian Hour 1

Debian is a Linux distribution — a free operating system built around the Linux kernel — and the base for Ubuntu, which most cloud AI servers (including the ones you'll deploy models to) run. Learning the shell now means you can SSH into any training server, cloud notebook, or Docker container later in the course without friction.

Why companies use it Nearly every production ML pipeline — training jobs, model-serving containers, cloud GPUs — runs on Linux, not Windows. Comfort at the shell is a baseline hiring filter for ML Engineer roles.

Basic Navigation Commands Hour 1

pwd, cd, and ls are how you know where you are and what's around you — the shell equivalent of opening File Explorer.

# where am I?
pwd

# move into a folder, then back up one level
cd datasets
cd ..

# list files; -l long format, -a shows hidden dotfiles
ls -la

# view a file's contents
cat README.md

# run a command as an administrator
sudo apt update

# read the manual for any command
man ls

# redirect output to a file instead of the screen
ls -la > filelist.txt

# create / remove directories and files
mkdir project_week1
rm old_notes.txt
rmdir empty_folder
cp data.csv data_backup.csv
mv data_backup.csv archive/
Common mistake rm does not go to a recycle bin — it deletes immediately. Always double-check the path before running rm -rf; a stray space (rm -rf / home instead of rm -rf /home) has genuinely destroyed production servers.

Reading Files & Aliases Hour 2

# cat dumps the whole file; more/less page through it
more bigfile.log
less bigfile.log      # q to quit, / to search

# head shows just the first lines — useful for peeking at a huge CSV
head -n 20 dataset.csv

# alias creates a shortcut for a longer command
alias ll='ls -la'
ll

System Control & File Editing Hour 3

# create an empty file, or update its timestamp
touch notes.txt

# open a simple terminal text editor
nano notes.txt        # Ctrl+O to save, Ctrl+X to exit

# bash / sh are the interpreters that run your shell scripts
bash myscript.sh
sh myscript.sh

# make a script executable, then run it
chmod +x myscript.sh
./myscript.sh

# see running processes; kill stops one by its PID
ps aux
kill 4521

# dpkg manages .deb package files directly
sudo dpkg -i package.deb

# shut down or reboot the machine
shutdown now
restart
Real world application ps and kill are exactly what you'll use when a runaway model training job is eating all the GPU memory on a shared server and needs to be stopped.

Package Management & Environment Variables Hour 4

# refresh the list of available packages, then upgrade installed ones
sudo apt update
sudo apt upgrade

# view, set, and use an environment variable
echo $PATH
export API_KEY="your-key-here"
echo $API_KEY
Security consideration Never hard-code an API key or secret directly into a script — set it as an environment variable (or a .env file excluded from Git) instead, so it never gets committed to a public repository like this one.

Python Fundamentals — Values, Strings & I/O

Hour 1–4 · Values & statements · Numbers, booleans, strings · Operators · Input & type casting

Values, Expressions & Statements Hour 1

A value is a piece of data (5, "hello", True). An expression combines values and operators into something that evaluates to a new value (5 + 3). A statement is a full instruction the interpreter executes, such as an assignment or a print call.

# values
5
"hello"
True

# expression — evaluates to 8
5 + 3

# statement — assigns the expression's result to a name
total = 5 + 3
print(total)

Numbers, Booleans & Strings Hour 1

# numeric types
age = 25          # int
price = 19.99      # float

# boolean type — exactly True or False
is_active = True

# string type — text in quotes
name = "Zuhaib"
message = 'Model training complete'

Operators, Variables & Keywords Hour 2

  • Arithmetic: + - * / // % **
  • Comparison: == != > < >= <=
  • Logical: and or not
  • Assignment: = += -= *= /=

Variables are names bound to values; keywords are words Python reserves for its own syntax (if, for, def, class, return, import …) and can't be used as variable names.

x = 10
y = 3
print(x // y)   # 3  — floor (integer) division
print(x % y)    # 1  — remainder
print(x ** y)   # 1000 — exponent
print(x > 5 and y < 5)  # True

String Operations Hour 2–3

first = "Machine"
second = "Learning"

print(first + " " + second)      # concatenation → "Machine Learning"
print(first * 2)                  # repetition → "MachineMachine"
print(len(first))                 # length → 7
print(first.upper())              # "MACHINE"
print(first.lower())              # "machine"
print(first[0])                   # indexing → "M"
print(first[0:4])                 # slicing → "Mach"
print(f"{first} {second} rocks")  # f-string formatting

Input, Type Casting & Comments Hour 4

# input() always returns a string
name = input("What is your name? ")

# type casting converts between types
age_text = input("Enter your age: ")
age = int(age_text)          # str → int
height = float("1.75")       # str → float
back_to_text = str(age)      # int → str

# this is a single-line comment
"""
This is a multi-line
comment / docstring
"""
Common error int(input("Age: ")) + 5 crashes with a ValueError if the user types "twenty" instead of "20" — always validate or wrap user input in a try/except before casting it.

Python Data Structures

Hour 1–4 · Lists & tuples · Dictionaries & sets

Lists Hour 1–2

An ordered, mutable (changeable) collection — the default container you'll reach for constantly, including for feature vectors and batches of training data.

features = [0.5, 1.2, 3.4, 2.1]

features.append(5.0)      # add to the end
features[0] = 0.9          # mutate by index
features.remove(2.1)       # remove a value
print(features[-1])        # negative indexing → last item
print(features[1:3])       # slicing
print(len(features))       # length
print(sorted(features))    # new sorted list

Tuples Hour 1–2

An ordered, immutable collection — use it for data that shouldn't change after creation, like a fixed (width, height) image shape.

image_shape = (224, 224, 3)   # height, width, channels
width, height, channels = image_shape   # unpacking

# image_shape[0] = 100   -> TypeError: tuples are immutable
Interview importance "When would you use a tuple instead of a list?" is a very common screening question. Answer: when the data shouldn't change, and when you want that guarantee enforced by the language rather than by convention — plus tuples are slightly faster and can be used as dictionary keys, which lists cannot.

Dictionaries Hour 3–4

An unordered collection of key → value pairs — how you'll represent a single labeled data record, model config, or JSON API response.

model_config = {
    "learning_rate": 0.001,
    "epochs": 50,
    "batch_size": 32
}

print(model_config["epochs"])          # 50
model_config["optimizer"] = "adam"      # add a new key
print(model_config.get("dropout", 0.0)) # safe lookup with default

for key, value in model_config.items():
    print(key, "→", value)

Sets Hour 3–4

An unordered collection of unique values — the natural tool for deduplicating a vocabulary of words or a list of class labels.

labels = ["cat", "dog", "cat", "bird", "dog"]
unique_labels = set(labels)
print(unique_labels)          # {'cat', 'dog', 'bird'}

a = {1, 2, 3}
b = {2, 3, 4}
print(a | b)   # union → {1,2,3,4}
print(a & b)   # intersection → {2,3}
print(a - b)   # difference → {1}

Conditional Execution & Loops

Hour 1–4 · If / elif / else · Break, continue, pass · While & for loops · Comprehensions & iterators

If, Elif, Else & Nested Conditionals Hour 1–2

accuracy = 0.87

if accuracy >= 0.9:
    print("Excellent model")
elif accuracy >= 0.75:
    print("Good model")
else:
    print("Needs more training")

# nested conditional
if accuracy >= 0.75:
    if accuracy >= 0.9:
        print("Ready to deploy")
    else:
        print("Good, but tune further first")

Break, Continue, Pass & Ternary Expressions Hour 1–2

for score in [0.4, 0.6, 0.95, 0.3]:
    if score < 0.5:
        continue          # skip low scores, go to next iteration
    if score >= 0.95:
        break              # stop entirely once we hit a great score
    print(score)

def todo():
    pass                   # placeholder — "fill this in later"

# ternary (conditional) expression — an if/else in one line
status = "pass" if accuracy >= 0.75 else "fail"

While & For Loops, and enumerate Hour 3–4

# while loop — repeats until the condition is false
epoch = 0
while epoch < 5:
    print("Training epoch", epoch)
    epoch += 1

# for loop over a list
labels = ["cat", "dog", "bird"]
for label in labels:
    print(label)

# enumerate gives you the index alongside each value
for i, label in enumerate(labels):
    print(i, "→", label)

Nested Loops, List Comprehension & Iterators/Iterables Hour 3–4

# nested loop — every combination of the two lists
for i in range(2):
    for j in range(3):
        print(i, j)

# list comprehension — build a new list in one line
squares = [n ** 2 for n in range(10)]
evens_only = [n for n in range(10) if n % 2 == 0]

# an iterable is anything you can loop over (list, string, dict...)
# an iterator is the object that actually tracks progress through it
numbers = [1, 2, 3]
it = iter(numbers)      # get an iterator from the iterable
print(next(it))          # 1
print(next(it))          # 2
Why this matters for ML Every training loop you write from Week 5 onward is a for loop over batches of data, and list comprehensions are the idiomatic way to preprocess a whole dataset in one readable line instead of four.

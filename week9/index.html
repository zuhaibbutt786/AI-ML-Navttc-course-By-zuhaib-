Word Embeddings — Word2Vec

Hour 2–4 · From one-hot to dense semantic vectors

Why Embeddings Beat One-Hot / BoW Hour 2

One-hot vectors treat every word as orthogonal — “cat” and “dog” are as different as “cat” and “quantum”. Word embeddings place each word in a continuous vector space (often 50–300 dimensions) so that related words land near each other. Arithmetic on those vectors recovers analogies and power downstream models with far fewer parameters than huge sparse bags.

# Conceptual: after training
vec("king") - vec("man") + vec("woman")  ≈  vec("queen")
vec("Paris") - vec("France") + vec("Italy") ≈ vec("Rome")

Video: Word2Vec — intuition and training objective

CBOW vs Skip-gram Hour 2–3

Word2Vec (Mikolov et al., 2013) trains a shallow net so that context predicts a word — or a word predicts its context:

VariantInputPredictsOften better when…
CBOW (Continuous Bag of Words) Context window around a targetThe target word Large data, frequent words, faster training
Skip-gram A single target word Words in its context window Smaller data, rare words, richer geometry 
Window size w = 2, sentence: "the quick brown fox jumps"
Skip-gram pairs for target "brown":
  (brown → quick), (brown → the), (brown → fox), (brown → jumps)
CBOW for target "brown":
  {the, quick, fox, jumps} → brown

Training uses hierarchical softmax or negative sampling so you do not compute a full softmax over the entire vocabulary every step.

Properties You Should Expect Hour 3–4

  • Cosine similarity ≈ semantic / syntactic relatedness
  • Linear analogies work surprisingly often (but not always)
  • Out-of-vocabulary (OOV) words need a strategy: <UNK>, subword models (FastText), or character CNNs
  • Domain matters: general Wikipedia embeddings ≠ medical or legal text
Modern context Static Word2Vec assigns one vector per word type. Contextual models (ELMo, BERT) give different vectors for “bank” in “river bank” vs “money bank”. You still need Word2Vec literacy: it is fast, interpretable, and a strong baseline for many production systems.

Gensim & Custom Embedding Training

Hour 1–4 · Train, inspect, and export vectors for Keras

Training Word2Vec with Gensim Hour 1–2

# pip install gensim
from gensim.models import Word2Vec

# sentences: list of token lists
sentences = [
    ["machine", "learning", "is", "fun"],
    ["deep", "learning", "uses", "neural", "networks"],
    ["natural", "language", "processing", "needs", "embeddings"],
    # ... thousands more lines from your corpus
]

model = Word2Vec(
    sentences,
    vector_size=100,   # embedding dimension
    window=5,
    min_count=2,
    sg=1,              # 1 = Skip-gram, 0 = CBOW
    negative=5,
    workers=4,
    epochs=10
)

print(model.wv.most_similar("learning", topn=5))
print(model.wv.similarity("machine", "deep"))
# Analogy: king - man + woman
print(model.wv.most_similar(positive=["king", "woman"], negative=["man"], topn=3))

Plug Embeddings into Keras Hour 3–4

import numpy as np
from tensorflow.keras.layers import Embedding

vocab = list(model.wv.index_to_key)
word2idx = {w: i + 1 for i, w in enumerate(vocab)}  # 0 reserved for pad
embed_dim = model.wv.vector_size
embedding_matrix = np.zeros((len(vocab) + 1, embed_dim))
for w, i in word2idx.items():
    embedding_matrix[i] = model.wv[w]

emb_layer = Embedding(
    input_dim=len(vocab) + 1,
    output_dim=embed_dim,
    weights=[embedding_matrix],
    trainable=False,          # freeze, or True to fine-tune
    mask_zero=True
)
Alignment The row index of each word in embedding_matrix must match the integer IDs your Tokenizer (or custom word2idx) produces. A single off-by-one error silently destroys performance.

Practical Training Tips

  • Clean and tokenize consistently with the downstream model
  • min_count filters noise; raise it on huge messy corpora
  • More epochs help small corpora; diminishing returns on very large ones
  • Evaluate with analogy sets and an actual task metric (classification F1)
  • FastText (subword n-grams) helps OOV and morphologically rich languages

Sequence Models — The Big Picture

Hour 1–4 · Mapping I/O shapes to architectures

Four Patterns You Must Recognize Hour 1–2

Almost every sequence application is one of these (or a composition of them):

PatternInputOutputExamples
1 → 1Fixed vectorFixed vector / classClassic MLP on engineered features
1 → ManyOne vector / imageSequenceImage captioning, conditional generation
Many → 1SequenceOne label / valueSentiment, document class, series anomaly score
Many → ManySequenceSequence (aligned or not)POS/NER (aligned), translation (encoder–decoder)

Week 8 focused on many→1 (LSTM classifier). This week makes the other shapes explicit and shows how encoder–decoder setups unlock unaligned many→many tasks.

Video: Sequence-to-sequence models overview

Encoder–Decoder Sketch Hour 3–4

Encoder:  x_1…x_T  →  RNN  →  context vector c  (last state or attention summary)
Decoder:  start → RNN(c) → y_1 → RNN → y_2 → … until end token

Teacher forcing feeds the true previous token during training; at inference the model consumes its own predictions (or beam search candidates). Attention (Week 10 direction) lets the decoder look at all encoder states instead of a single fixed vector.

1 → 1 and 1 → Many

Hour 1–4 · Fixed inputs and sequence generation from a seed

1 → 1 — Still Relevant Hour 1

When features are already a fixed vector (tabular + pretrained sentence embedding, pooled CNN features), a Dense head is a 1→1 map. You already built these in Weeks 5–7. The new idea is: obtain that vector from a frozen encoder (Word2Vec mean-pool, or a CNN/RNN encoder) then classify.

# Mean-pool Word2Vec vectors → logistic / MLP head
def doc_vector(tokens, kv):
    vecs = [kv[w] for w in tokens if w in kv]
    return np.mean(vecs, axis=0) if vecs else np.zeros(kv.vector_size)

1 → Many — Generate a Sequence from One Vector Hour 2–4

Classic uses: image captioning (CNN image vector → LSTM decoder) and conditional language models that start from a topic or style embedding.

from tensorflow.keras import layers, models

# Decoder conditioned on a fixed context vector c (e.g. image features)
context_dim = 256
vocab_size = 5000
max_len = 20

image_input = layers.Input(shape=(context_dim,))
x = layers.RepeatVector(max_len)(image_input)          # tile c across time
x = layers.LSTM(128, return_sequences=True)(x)
out = layers.TimeDistributed(layers.Dense(vocab_size, activation='softmax'))(x)
caption_model = models.Model(image_input, out)
caption_model.compile(optimizer='adam', loss='sparse_categorical_crossentropy')
Inference Generation is usually autoregressive: feed the predicted token back in, or use predict step-by-step with a start token. Greedy decoding is simple; beam search improves quality at higher cost.

Many → 1 and Many → Many

Hour 1–4 · Classification from sequences and aligned / unaligned sequence outputs

Many → 1 — Sequence Classification (Recap + Embeddings) Hour 1–2

from tensorflow.keras import layers, models

model = models.Sequential([
    layers.Embedding(input_dim=10001, output_dim=100, mask_zero=True,
                     weights=[embedding_matrix], trainable=True),
    layers.Bidirectional(layers.LSTM(64)),
    layers.Dropout(0.3),
    layers.Dense(1, activation='sigmoid')
])
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

Compare: trainable random Embedding vs frozen Word2Vec vs fine-tuned Word2Vec. Fine-tuning often wins when you have enough labeled data.

Many → Many (Aligned) — Token Tagging Hour 2–3

n_tags = 9   # e.g. BIO NER tags
tagger = models.Sequential([
    layers.Embedding(10001, 100, mask_zero=True),
    layers.Bidirectional(layers.LSTM(64, return_sequences=True)),
    layers.TimeDistributed(layers.Dense(n_tags, activation='softmax'))
])
tagger.compile(optimizer='adam', loss='sparse_categorical_crossentropy')

Each input token maps to one output tag. Padding must be masked so pad positions do not dominate the loss.

Many → Many (Unaligned) — Encoder–Decoder Hour 3–4

# Minimal seq2seq without attention
latent = 128
encoder_inputs = layers.Input(shape=(None,))
enc_emb = layers.Embedding(src_vocab, 64, mask_zero=True)(encoder_inputs)
_, state_h, state_c = layers.LSTM(latent, return_state=True)(enc_emb)
encoder_states = [state_h, state_c]

decoder_inputs = layers.Input(shape=(None,))
dec_emb = layers.Embedding(tgt_vocab, 64, mask_zero=True)(decoder_inputs)
dec_lstm = layers.LSTM(latent, return_sequences=True, return_state=True)
dec_out, _, _ = dec_lstm(dec_emb, initial_state=encoder_states)
dec_dense = layers.Dense(tgt_vocab, activation='softmax')
decoder_outputs = dec_dense(dec_out)

seq2seq = models.Model([encoder_inputs, decoder_inputs], decoder_outputs)
seq2seq.compile(optimizer='adam', loss='sparse_categorical_crossentropy')

Week 9 Cheat Sheet

Word2Vec

CBOW:   context → target     (fast, good on frequent words)
Skip-gram: target → context  (better on rare words, richer geometry)
Gensim: Word2Vec(..., sg=1, vector_size=100, window=5, min_count=2)
Export matrix → Keras Embedding(weights=[matrix], trainable=...)

Sequence patterns

1 → 1        Dense / MLP on fixed features
1 → Many     RepeatVector / decoder from seed (captions)
Many → 1     RNN/CNN encoder → Dense (sentiment)
Many → Many  return_sequences + TimeDistributed (tags)
             or encoder–decoder (translation)

Keras reminders

mask_zero=True on Embedding when 0 is pad
return_sequences=True for token-level outputs or stacked RNNs
TimeDistributed(Dense(...)) for per-timestep classifiers
Freeze embeddings: trainable=False; fine-tune later if needed

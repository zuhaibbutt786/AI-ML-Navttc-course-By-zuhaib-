Process Videos on Azure

Hour 2–4 · Insights from media without training a video net from scratch

Why Video APIs? Hour 2

Custom video models (action recognition, dense captioning) need heavy data and GPUs. Azure AI Video Indexer (and related media services) extract practical insights from uploaded or URL-based media:

  • Speech-to-text transcripts and captions
  • Keyword / topic extraction
  • Scene and shot boundaries
  • OCR on frames
  • Face/celebrity/object insights where enabled and allowed by policy
  • Sentiment over time on spoken content

Typical Workflow Hour 2–3

1. Create Video Indexer account / ARM account linked to Azure subscription
2. Upload video or provide URL
3. Index (choose language, privacy mode)
4. Retrieve insights JSON via portal or API
5. Surface captions, keywords, or search in your app
# Conceptual: call insights after indexing completes
# GET https://api.videoindexer.ai/{location}/Accounts/{accountId}/Videos/{videoId}/Index
# Headers: Ocp-Apim-Subscription-Key or OAuth token
# Parse: videos[0].insights.transcript, keywords, sentiments, ...

Design Notes Hour 3–4

  • Match indexing language to spoken audio for better transcripts
  • Privacy: restrict face identification when not required
  • Cost scales with hours processed — trim long archives before indexing
  • Combine with Week 11 vision for key-frame still analysis when needed
Product idea Training-video search: index internal lectures, then let staff search by spoken keyword and jump to the timestamp — a strong employable demo for education and enterprise.

Azure NLP — Text, Speech, Translation

Hour 1–4 · Language service, Speech service, Translator

Analyze Text (Language Service) Hour 1–2

Azure AI Language covers the classic text analytics suite:

  • Sentiment analysis (document and sentence level)
  • Key phrase extraction
  • Named entity recognition (NER) and PII detection
  • Language detection
  • Summarization (extractive / abstractive where available)
# pip install azure-ai-textanalytics
from azure.ai.textanalytics import TextAnalyticsClient
from azure.core.credentials import AzureKeyCredential

client = TextAnalyticsClient(endpoint, AzureKeyCredential(key))
docs = [
    "Azure makes it easier to ship NLP features in production.",
    "The delivery was late and support was unhelpful."
]
result = client.analyze_sentiment(docs, show_opinion_mining=True)
for doc in result:
    print(doc.sentiment, doc.confidence_scores)

Process Speech Hour 2–3

# pip install azure-cognitiveservices-speech
import azure.cognitiveservices.speech as speechsdk

speech_config = speechsdk.SpeechConfig(subscription=speech_key, region=region)
speech_config.speech_recognition_language = "en-US"

# From microphone
audio_config = speechsdk.audio.AudioConfig(use_default_microphone=True)
recognizer = speechsdk.SpeechRecognizer(speech_config=speech_config, audio_config=audio_config)
result = recognizer.recognize_once()
print(result.text)

# Text-to-speech
speech_config.speech_synthesis_voice_name = "en-US-JennyNeural"
synthesizer = speechsdk.SpeechSynthesizer(speech_config=speech_config)
synthesizer.speak_text_async("Course complete. Well done.").get()

Also explore continuous recognition, speech translation, and pronunciation assessment for education apps.

Language Understanding & Question Answering

Hour 1–4 · Intents, entities, and grounded answers from your content

Conversational Language Understanding (CLU) Hour 1–2

CLU (evolution of LUIS patterns) maps user utterances to intents and entities:

User: "Book a lab room tomorrow at 3pm"
Intent: ScheduleLab
Entities: datetime → tomorrow 15:00, location_type → lab
  1. Create a Language resource + CLU project in Language Studio
  2. Define intents (ScheduleLab, CancelBooking, GetHours, None)
  3. Add example utterances and label entities
  4. Train, evaluate precision/recall, deploy an endpoint
  5. Call from your bot or backend

Question Answering Hour 2–4

Custom question answering (successor concepts to QnA Maker) builds a knowledge base from FAQs, product docs, or URLs and returns answers with confidence scores.

1. Create QA project in Language Studio
2. Add chit-chat + custom sources (files/URLs)
3. Review question–answer pairs; add alternate questions
4. Deploy
5. Query: client.get_answers(question="How do I reset my password?", ...)
Grounding Always show the source and confidence. Low-confidence answers should fall back to a human agent or a safe default — especially for medical, legal, or financial content.

Knowledge Mining Solutions

Hour 2–4 · Unlock insights from large unstructured document sets

What Knowledge Mining Is Hour 2

Enterprises sit on PDFs, scans, emails, and shares full of locked knowledge. Knowledge mining on Azure typically combines:

  • Azure AI Search (formerly Cognitive Search) with skillsets
  • OCR, language detection, key phrases, entity extraction skills
  • Custom skills (Azure Functions) for domain logic
  • An index your applications query

Pipeline Sketch Hour 2–4

Blob Storage (documents)
  → Indexer
  → Skillset (OCR → Language → KeyPhrases → Entities → custom skill)
  → Search Index
  → Your app / bot / dashboard queries the index

This is how you build internal “search anything we own” experiences — a frequent enterprise project type and a strong portfolio story when scoped to one department’s docs.

Tie-in Week 6–9 NLP skills help you understand what the skills are doing; Azure runs them at scale with scheduling, incremental indexing, and security trimmings.

Conversational AI Solutions

Hour 1–4 · Bots that combine CLU, QA, and speech

Bot Architecture Pattern Hour 1–2

Channels (Teams, Web Chat, WhatsApp via adapter)
  → Bot Service / bot code (SDK)
      → CLU  (intent routing)
      → Question Answering  (FAQ answers)
      → Speech  (optional voice)
      → Your APIs  (bookings, CRM)
  → Response + logging + handoff to human

Implementation Path for Students Hour 2–3

  1. Compose a CLU model for 4–6 intents
  2. Add a small QA knowledge base from a course FAQ
  3. Build a simple bot (Bot Framework SDK or Composer / Studio path)
  4. Test in Web Chat; log utterances that fall to None intent
  5. Iterate examples; document limitations honestly

Production Concerns Hour 3–4

  • Authentication on channels; never trust client-side identity alone
  • PII in logs — redact before storage
  • Human handoff when confidence is low
  • Telemetry: intent distribution, fallback rate, user satisfaction
  • Responsible AI: blocked topics, abuse handling, clear bot identity

About this course

This site is a full interactive version of the official NAVTTC (National Vocational and Technical Training Commission) Artificial Intelligence (Machine Learning & Deep Learning) curriculum under the Prime Minister’s Hunarmand Pakistan / Skills for All program.

It is designed so non-technical beginners can follow along: plain-language explanations, worked Python examples, self-check quizzes, cheat sheets, and links to trusted visual explainers (neural network animations, data visualization guides, and GeeksforGeeks-style references) wherever they help.

  • 12 weeks · ~20 hours of class structure per week
  • Linux → Python → Statistics → ML → NLP → Deep Learning → Azure AI
  • Slide mode, MCQs, projects, and employable project guidance
  • Free to learn online · MIT licensed materials on GitHub

Recurrent Neural Networks (RNNs)

Hour 2–4 · Memory over time, BPTT, and why plain RNNs struggle

Why Sequences Need Recurrence Hour 2

An MLP maps a fixed-size vector to an output. A sentence can be 5 words or 50; a sensor trace can be 100 steps or 10,000. Recurrent models process the sequence step by step, carrying a hidden state that summarizes what has been seen so far:

h_t = tanh(W_hh h_{t-1} + W_xh x_t + b)
y_t = W_hy h_t + b_y     # optional output at each step

The same weights are reused at every time step — the network “rolls out” in time. That weight sharing is what lets one model handle variable-length inputs.

  • Many-to-one: whole sequence → one label (sentiment, anomaly score)
  • Many-to-many: sequence → sequence (POS tags, translation encoder states)
  • One-to-many: seed → sequence (image captioning, generation)

Video: Recurrent Neural Networks — intuitive overview

Backpropagation Through Time (BPTT) Hour 3

Training unrolls the net for T steps and applies the chain rule across time. Gradients flow backward from the loss at step T all the way to step 1. In practice we often use truncated BPTT — backprop only through the last k steps — for memory and stability.

# Conceptual Keras SimpleRNN (many-to-one classifier)
from tensorflow.keras import layers, models

model = models.Sequential([
    layers.Embedding(input_dim=10000, output_dim=64, input_length=200),
    layers.SimpleRNN(64),
    layers.Dense(1, activation='sigmoid')
])
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

The Vanishing (and Exploding) Gradient Problem in Time Hour 3–4

As gradients multiply through many time steps, they often shrink toward zero. Early tokens stop influencing the loss — the network “forgets” the beginning of a long sequence. Exploding gradients (large products) cause NaNs; gradient clipping is the usual fix for those.

Why this matters Plain SimpleRNN is a teaching tool. For real tasks with long dependencies you almost always reach for LSTM or GRU (Days 2–5) — or, later, Transformers.

Mitigations used historically and still useful:

  • Gradient clipping (clipnorm / clipvalue in optimizers)
  • Careful initialization
  • Gated cells (LSTM, GRU) that learn what to remember and what to forget

Long Short-Term Memory (LSTM)

Hour 1–4 · Gates, cell state, and long-range memory

The Core Idea — A Highway for Gradients Hour 1–2

LSTM (Hochreiter & Schmidhuber, 1997) adds an explicit cell state c_t that runs through time with only minor linear interactions. Gates control what enters, what is forgotten, and what is exposed as the hidden output:

f_t = σ(W_f · [h_{t-1}, x_t] + b_f)     # forget gate
i_t = σ(W_i · [h_{t-1}, x_t] + b_i)     # input gate
c̃_t = tanh(W_c · [h_{t-1}, x_t] + b_c)  # candidate cell
c_t = f_t ⊙ c_{t-1} + i_t ⊙ c̃_t         # new cell state
o_t = σ(W_o · [h_{t-1}, x_t] + b_o)     # output gate
h_t = o_t ⊙ tanh(c_t)                   # hidden output
  • Forget gate — how much of the old cell to keep
  • Input gate — how much of the new candidate to write
  • Output gate — how much of the cell to expose as h_t

Because c_t is mostly additive, gradients can flow across many steps without repeated multiplication by small factors — the practical cure for vanishing gradients in time.

LSTM in Keras Hour 2–4

from tensorflow.keras import layers, models

# Many-to-one text classifier
model = models.Sequential([
    layers.Embedding(10000, 64, input_length=200),
    layers.LSTM(64),                    # returns last hidden state by default
    layers.Dropout(0.3),
    layers.Dense(1, activation='sigmoid')
])
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])

# Stacked LSTM — return sequences to the next LSTM
stacked = models.Sequential([
    layers.Embedding(10000, 64, input_length=200),
    layers.LSTM(64, return_sequences=True),
    layers.LSTM(32),
    layers.Dense(1, activation='sigmoid')
])

# Bidirectional LSTM — read past and future context
bi = models.Sequential([
    layers.Embedding(10000, 64, input_length=200),
    layers.Bidirectional(layers.LSTM(32)),
    layers.Dense(1, activation='sigmoid')
])
return_sequences return_sequences=True when the next layer needs the full time axis (stacked RNN, attention, token-level labels). Leave it False (default) for a single vector summary into a Dense head.

def make_windows(series, window=30):
    X, y = [], []
    for i in range(len(series) - window):
        X.append(series[i:i+window])
        y.append(series[i+window])

Sampling tip At generation time, divide logits by a temperature T before softmax. T < 1 → sharper / more confident; T > 1 → more random. This is a standard control for creative vs conservative text.

Debugging LSTM Training

  • Loss NaN → clip gradients, lower lr, check padding/masking
  • Overfit fast → dropout / recurrent_dropout, fewer units, more data
  • Ignores early tokens → try Bidirectional, or longer training; confirm maxlen is enough
  • Slow on CPU → smaller units, shorter sequences, or GPU

Gated Recurrent Unit (GRU)

Hour 1–4 · A lighter gate design that often matches LSTM quality

GRU vs LSTM Hour 1–2

GRU (Cho et al., 2014) simplifies the LSTM gating structure:

  • Combines forget and input into a single update gate
  • Uses a reset gate to control how much past state enters the candidate
  • No separate cell state — the hidden state carries memory
z_t = σ(W_z · [h_{t-1}, x_t])          # update gate
r_t = σ(W_r · [h_{t-1}, x_t])          # reset gate
h̃_t = tanh(W · [r_t ⊙ h_{t-1}, x_t])  # candidate
h_t = (1 − z_t) ⊙ h_{t-1} + z_t ⊙ h̃_t  # interpolate
LSTMGRU
Gates3 (forget, input, output)2 (update, reset)
Statescell + hiddenhidden only
ParametersMoreFewer → often faster
QualityStrong baselineOften similar on many tasks

Rule of thumb: try GRU first when you want speed; switch to LSTM if validation plateaus and you can afford extra capacity. Both beat SimpleRNN on long dependencies.

Week 8 Cheat Sheet

Architecture at a glance

SimpleRNN:  h_t = tanh(W_h h_{t-1} + W_x x_t)
LSTM:       gates f, i, o + cell state c_t  (best long memory, more params)
GRU:        gates z, r + hidden only         (fewer params, often as good)

Keras flags you will use constantly

return_sequences=True   # pass full sequence to next layer
return_state=True       # also return final state(s) — encoder style
Bidirectional(...)      # forward + backward
mask_zero=True          # on Embedding when 0 = pad
dropout / recurrent_dropout

Training checklist

1. Pad / truncate to maxlen; mask pads
2. Embedding → RNN → Dense
3. Adam + binary_crossentropy or sparse_categorical_crossentropy
4. Clipnorm if gradients explode
5. EarlyStopping on val_loss
6. Compare GRU vs LSTM on your metric and budget

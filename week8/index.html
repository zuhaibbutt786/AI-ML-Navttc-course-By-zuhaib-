Recurrent Neural Networks (RNNs)

Hour 1–4 · Sequence modelling, the recurrence, vanishing gradients

Why Sequences Need Memory Hour 1

A bag-of-words or a 1D CNN sees a fixed window. An RNN keeps a hidden state that is updated at every time step, so information from the start of a sentence can still influence the prediction at the end:

hₜ = tanh(Wₕₕ hₜ₋₁ + Wₓₕ xₜ + b)
ŷₜ = softmax(Wₕᵧ hₜ + bᵧ)

The same weight matrices are reused at every step — that is the “recurrent” part. Unrolled over a sequence of length T, the graph looks like a deep chain of T layers that share parameters.

  • Many-to-one: whole sequence → one label (sentiment, topic)
  • Many-to-many: sequence → sequence (NER, translation, tagging)
  • One-to-many: seed → generated sequence (image caption, text generation)

Video: Recurrent Neural Networks — intuitive overview

Vanishing & Exploding Gradients on Sequences Hour 2–3

When you backpropagate through time (BPTT), the gradient is multiplied by the same recurrent matrix at every step. If the largest singular value of that matrix is < 1, gradients shrink exponentially with sequence length (vanishing). If > 1, they explode.

  • Symptom of vanishing: the model only uses the last few tokens; early context is ignored
  • Symptom of exploding: loss becomes NaN; weights grow without bound
  • Mitigations before LSTM: gradient clipping, careful init, shorter sequences, truncated BPTT
Key insight Plain RNNs struggle to learn dependencies longer than ~10–20 steps. That is why almost nobody ships a vanilla RNN for real text or audio anymore — LSTM / GRU (and later Transformers) solved the practical memory problem.

A Minimal NumPy RNN Step Hour 3–4

import numpy as np

def rnn_step(x_t, h_prev, Wxh, Whh, Why, bh, by):
    """One time step of a simple RNN."""
    h = np.tanh(Whh @ h_prev + Wxh @ x_t + bh)
    y = Why @ h + by
    return h, y

Long Short-Term Memory (LSTM)

Hour 1–4 · Gates, cell state, and why LSTMs remember

The Cell State Highway Hour 1

An LSTM adds a cell state cₜ that runs through the sequence with only minor linear interactions. Three gates (sigmoid outputs in [0, 1]) control what is written, forgotten, and read:

fₜ = σ(W_f · [hₜ₋₁, xₜ] + b_f)     # forget gate
iₜ = σ(W_i · [hₜ₋₁, xₜ] + b_i)     # input gate
c̃ₜ = tanh(W_c · [hₜ₋₁, xₜ] + b_c)  # candidate cell
cₜ = fₜ ⊙ cₜ₋₁ + iₜ ⊙ c̃ₜ           # new cell state
oₜ = σ(W_o · [hₜ₋₁, xₜ] + b_o)     # output gate
hₜ = oₜ ⊙ tanh(cₜ)                 # hidden output

Because the cell update is mostly additive, gradients can flow for hundreds of steps without vanishing. That is the core design win of the 1997 Hochreiter & Schmidhuber paper.

Bidirectional & Stacked LSTMs Hour 3–4

Bidirectional LSTM runs one LSTM left-to-right and another right-to-left, then concatenates the hidden states. Useful when the whole sequence is available at once (document classification, NER) — not for pure online generation.

Stacked (deep) LSTM puts several LSTM layers on top of each other so higher layers see more abstract temporal features. Typical depth in practice: 1–3 layers before Transformers took over large-scale NLP.

Hour 1–4 · Sentiment classifier and sequence modelling in Keras

Many-to-One: Sentiment with Embedding + LSTM Hour 1–2

import tensorflow as tf
from tensorflow.keras import layers, models

vocab_size = 10000
max_len = 200
embed_dim = 64
lstm_units = 64

model = models.Sequential([
    layers.Embedding(vocab_size, embed_dim, input_length=max_len, mask_zero=True),
    layers.LSTM(lstm_units, dropout=0.2, recurrent_dropout=0.2),
    layers.Dense(32, activation='relu'),
    layers.Dropout(0.3),
    layers.Dense(1, activation='sigmoid')
])

model.compile(
    optimizer=tf.keras.optimizers.Adam(1e-3),
    loss='binary_crossentropy',
    metrics=['accuracy', tf.keras.metrics.AUC(name='auc')]
)

Return Sequences & Stacked LSTM Hour 2–3

model = models.Sequential([
    layers.Embedding(vocab_size, embed_dim, input_length=max_len, mask_zero=True),
    layers.LSTM(128, return_sequences=True, dropout=0.2),
    layers.LSTM(64, dropout=0.2),
    layers.Dense(1, activation='sigmoid')
])

First LSTM outputs a sequence of hidden states; the second LSTM reads that sequence and collapses it to a single vector for classification.

Gated Recurrent Unit (GRU)

Hour 1–4 · A lighter alternative to LSTM

Fewer Gates, Same Idea Hour 1–2

The GRU (Cho et al., 2014) merges the forget and input gates into a single update gate and combines cell and hidden state into one vector:

zₜ = σ(W_z · [hₜ₋₁, xₜ])          # update gate
rₜ = σ(W_r · [hₜ₋₁, xₜ])          # reset gate
h̃ₜ = tanh(W · [rₜ ⊙ hₜ₋₁, xₜ])    # candidate
hₜ = (1 − zₜ) ⊙ hₜ₋₁ + zₜ ⊙ h̃ₜ

Result: fewer parameters, often similar accuracy to LSTM on many sequence tasks, slightly faster training. When in doubt, try both; the difference is rarely dramatic on medium-sized data.

Keras GRU in One Block Hour 2–3

model = models.Sequential([
    layers.Embedding(vocab_size, 64, input_length=max_len, mask_zero=True),
    layers.GRU(64, dropout=0.2, recurrent_dropout=0.2),
    layers.Dense(1, activation='sigmoid')
])

model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['accuracy'])
# model.fit(...)

API is intentionally parallel to LSTM: same arguments for return_sequences, dropout, recurrent_dropout, bidirectional wrappers, etc.

Debugging Playbook for Sequence Models

  • Loss NaN → lower learning rate, clipnorm=1.0 on the optimizer, check for empty sequences
  • Model ignores early tokens → try LSTM/GRU instead of plain RNN, increase units, bidirectional
  • Severe overfitting → more dropout / recurrent_dropout, smaller embedding, more data
  • Slow training → reduce max_len, use CuDNN-friendly settings (no recurrent_dropout on GPU), or switch to GRU

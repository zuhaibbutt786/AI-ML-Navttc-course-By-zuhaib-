Selecting Azure AI Services

Hour 2–4 · Match the problem to the right managed API

Build vs Buy (API) Hour 2

Training a custom CNN or BiLSTM is powerful — and expensive in time, data, and compute. Azure AI (formerly Cognitive Services and related Applied AI) offers prebuilt models behind REST / SDK APIs. Use them when:

  • The task is standard (OCR, generic image tags, translation, sentiment)
  • You need a production endpoint quickly
  • You lack labeled data for a full custom model

Train your own model (Weeks 5–10 skills) when the domain is specialized, latency/cost at scale favors a compact local model, or compliance requires on-prem weights.

Security, Auth & Responsible AI

Hour 1–4 · Keys, identity, networks, and ethical constraints

Authentication Patterns Hour 1–2

  • API keys — simplest for demos; rotate regularly; never commit to Git
  • Azure AD / Microsoft Entra ID — managed identity or service principal for production
  • Endpoint + key — every SDK client needs the resource endpoint URL and a credential
# Environment variables — preferred over hardcoding
# export VISION_ENDPOINT="https://YOUR-RESOURCE.cognitiveservices.azure.com/"
# export VISION_KEY="your-key"
import os
endpoint = os.environ["VISION_ENDPOINT"]
key = os.environ["VISION_KEY"]

Network & Key Hygiene Hour 2–3

  • Regenerate keys if leaked; use Key Vault for secrets in real deployments
  • Restrict access with Azure Virtual Network / private endpoints when data is sensitive
  • Separate dev and prod resources; least-privilege RBAC roles
  • Enable diagnostic logging for audit trails

Responsible AI Principles Hour 3–4

Microsoft’s Responsible AI guidance (and good engineering practice) emphasizes:

  • Fairness — monitor skewed error rates across groups where relevant
  • Reliability & safety — handle low-confidence outputs; human review for high stakes
  • Privacy & security — minimize data retention; respect consent
  • Inclusiveness — test on diverse inputs (languages, lighting, accents)
  • Transparency — document what the system does and does not do
  • Accountability — clear ownership and escalation paths
Face & biometrics Face recognition and some biometric scenarios are tightly restricted by policy and law. Always check current Azure product terms and local regulations before designing a face-based feature.

Create & Manage Azure AI Resources

Hour 1–4 · Portal workflow, logging, cost, monitoring

Create a Resource Hour 1–2

  1. Azure portal → Create a resource → search Azure AI services or a specific product (e.g. Computer Vision, Azure AI Vision)
  2. Choose subscription, resource group, region, pricing tier (F0 free tier where available for learning)
  3. After deploy: open the resource → Keys and Endpoint
  4. Install SDK, e.g. pip install azure-ai-vision-imageanalysis or the current Computer Vision package for your API version
Multi-service vs single A multi-service Azure AI resource can unlock several Cognitive APIs under one endpoint/key. Single-service resources isolate quotas and billing. For class demos, multi-service or free tier is fine; for production, plan quotas explicitly.

Diagnostic Logging & Monitoring Hour 2–3

  • Enable diagnostic settings → send logs to Log Analytics, Storage, or Event Hub
  • Watch metrics: calls, latency, error rate, throttling (429)
  • Set alerts on elevated failures or spend

Cost Management Hour 3–4

  • Prefer free / free-trial tiers for coursework; know call limits
  • Cache results when the same image/text is analyzed repeatedly
  • Use the cheapest region that meets latency and data-residency needs
  • Delete unused resources; set budgets and alerts on the subscription

cache_key = hash(image_bytes)

Deploying Azure AI Solutions

Hour 1–4 · Endpoints, containers, CI/CD awareness

Consumption vs Containers Hour 1–2

  • Cloud endpoint — default; Azure hosts the model; you call HTTPS
  • Docker containers — run selected Cognitive Services in your own environment (connected or disconnected tiers where licensed) for data residency or low latency

Plan: default endpoint for learning; evaluate containers when compliance forbids data leaving a VNet or site.

CI/CD Integration Hour 2–3

Build app → run unit tests →
  inject endpoint/key from pipeline secrets →
  integration test against staging resource →
  deploy app (Azure App Service, Functions, AKS, VM)
  • Never store keys in YAML; use variable groups / Key Vault references
  • Smoke-test one vision and one language call after deploy
  • Pin SDK versions to avoid surprise breaking changes

Anomaly Detection & Content Safety (Awareness) Hour 3–4

Decision-oriented services complement vision/language:

  • Anomaly Detector — univariate/multivariate time series outliers (IoT, metrics)
  • Content Moderator / Content Safety — text and image moderation for UGC platforms

Use them as building blocks inside a larger solution rather than as the whole product.

Image Analysis (Computer Vision) Hour 1–2

# Illustrative SDK usage — package names evolve; check current Azure docs
# pip install azure-cognitiveservices-vision-computervision
from azure.cognitiveservices.vision.computervision import ComputerVisionClient
from msrest.authentication import CognitiveServicesCredentials

client = ComputerVisionClient(endpoint, CognitiveServicesCredentials(key))

with open("warehouse.jpg", "rb") as f:
    analysis = client.analyze_image_in_stream(
        f,
        visual_features=["Tags", "Objects", "Description", "Adult"]
    )

print(analysis.description.captions[0].text if analysis.description.captions else "")
print([t.name for t in analysis.tags[:10]])
print([o.object_property for o in analysis.objects])

OCR / Read API Hour 2

# Async read pattern is common for dense documents
with open("invoice.png", "rb") as f:
    poller = client.read_in_stream(f, raw=True)
operation_id = poller.headers["Operation-Location"].split("/")[-1]

import time
while True:
    result = client.get_read_result(operation_id)
    if result.status not in ["notStarted", "running"]:
        break
    time.sleep(1)

if result.status == "succeeded":
    for page in result.analyze_result.read_results:
        for line in page.lines:
            print(line.text)

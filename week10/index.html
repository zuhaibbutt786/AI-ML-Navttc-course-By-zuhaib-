Bidirectional LSTM / RNN in Sequence Models

Hour 2–4 · Full left–right context (Task 65)

Why Bidirectional? Hour 2

A standard LSTM only sees the past. For offline tasks — document classification, NER, speech transcription of a full utterance — the future tokens are available and informative. A Bidirectional RNN runs one recurrent net forward and one backward, then concatenates (or adds) the hidden states at each step:

h⃗_t = RNN_forward(x_t, h⃗_{t-1})
h⃖_t = RNN_backward(x_t, h⃖_{t+1})
h_t  = [h⃗_t ; h⃖_t]     # concatenation is the common choice

The model can use “the bank of the river” vs “the bank approved the loan” with both sides of context — critical for disambiguation.

Video: Bidirectional RNNs — when future context is allowed

Keras Bidirectional Patterns Hour 2–3

from tensorflow.keras import layers, models

# Many → 1 document classifier
clf = models.Sequential([
    layers.Embedding(10000, 64, mask_zero=True),
    layers.Bidirectional(layers.LSTM(64)),
    layers.Dense(1, activation='sigmoid')
])

# Many → many token tagger
tagger = models.Sequential([
    layers.Embedding(10000, 64, mask_zero=True),
    layers.Bidirectional(layers.LSTM(64, return_sequences=True)),
    layers.TimeDistributed(layers.Dense(n_tags, activation='softmax'))
])

# Stacked bidirectional
deep = models.Sequential([
    layers.Embedding(10000, 64, mask_zero=True),
    layers.Bidirectional(layers.LSTM(64, return_sequences=True)),
    layers.Bidirectional(layers.LSTM(32)),
    layers.Dense(1, activation='sigmoid')
])

When Bidirectional Is Wrong Hour 3–4

  • Real-time / streaming — future tokens are not available (live speech, online chat scoring)
  • Causal language modeling — predicting the next token must not peek ahead
  • Some production latency budgets — two directions ≈ 2× compute
Integrity Using Bidirectional on a task that will later be deployed as streaming is a common train/serve skew. Design the architecture for the real deployment constraint from day one.

Attention Mechanism in Models

Hour 1–4 · Soft alignment between decoder queries and encoder states

The Bottleneck Problem Hour 1

Basic seq2seq (Week 9) compresses an entire source sequence into one fixed vector. Long sentences lose detail. Attention lets the decoder, at each output step, look at all encoder hidden states and form a weighted summary focused on the relevant positions.

Video: Attention in neural networks — intuition

Bahdanau-Style Attention (Additive) Hour 2

For decoder step t, with query s_t (decoder state) and encoder states h_1…h_T:

score_i = vᵀ tanh(W_s s_t + W_h h_i)     # how well h_i matches query
α_i     = softmax(score)_i                 # attention weights
c_t     = Σ_i α_i h_i                      # context vector
# decoder then uses [s_t ; c_t] to predict y_t

The α weights are a soft alignment — you can plot them and often see the model “looking at” the right source words while generating each target word.

Luong-Style Attention (Dot / General / Concat) Hour 2–3

score_i = s_tᵀ h_i              # dot
score_i = s_tᵀ W h_i            # general
# then same softmax → context c_t

Dot-product attention is simple and fast when dimensions match. Scaled dot-product (divide by √d) is the building block of Transformers.

Self-Attention Preview Hour 3–4

In Transformers, every position attends to every other position in the same sequence (self-attention). Queries, keys, and values are linear projections of the same inputs. You do not need a separate RNN. For this curriculum week, master encoder–decoder attention first; treat self-attention as the natural next idea.

Industry note Attention maps are useful for debugging and for light explainability (“the model focused on these tokens”). They are not a full legal explanation, but they beat a pure black box.

Attention — Implementation Practice

Hour 1–4 · Keras building blocks and a minimal attentive decoder

Keras Attention Layer Hour 1–2

from tensorflow.keras import layers, models

# Encoder
enc_in = layers.Input(shape=(None,))
enc_emb = layers.Embedding(src_vocab, 64, mask_zero=True)(enc_in)
enc_out = layers.Bidirectional(layers.LSTM(64, return_sequences=True))(enc_emb)

# Decoder query (simplified: last decoder state repeated — real models step through time)
dec_in = layers.Input(shape=(None,))
dec_emb = layers.Embedding(tgt_vocab, 64, mask_zero=True)(dec_in)
dec_lstm_out = layers.LSTM(128, return_sequences=True)(dec_emb)

# Attention: query=decoder, value/key=encoder outputs
ctx = layers.Attention()([dec_lstm_out, enc_out])
concat = layers.Concatenate()([dec_lstm_out, ctx])
out = layers.TimeDistributed(layers.Dense(tgt_vocab, activation='softmax'))(concat)

model = models.Model([enc_in, dec_in], out)
model.compile(optimizer='adam', loss='sparse_categorical_crossentropy')

Attention for Classification (Many → 1) Hour 2–3

You can also attend over a single sequence to form a weighted document vector instead of using only the last LSTM state:

inputs = layers.Input(shape=(None,))
x = layers.Embedding(10000, 64, mask_zero=True)(inputs)
h = layers.Bidirectional(layers.LSTM(64, return_sequences=True))(x)
# Learnable query via a Dense scoring each timestep
score = layers.Dense(1)(h)                    # (batch, T, 1)
weights = layers.Softmax(axis=1)(score)
context = layers.Dot(axes=1)([weights, h])    # (batch, 1, 2*64)
context = layers.Flatten()(context)
out = layers.Dense(1, activation='sigmoid')(context)
attn_clf = models.Model(inputs, out)

What to Inspect Hour 3–4

  • Plot α over source tokens for a few examples — does it look sensible?
  • Compare val loss with vs without attention on the same data budget
  • Watch for attention collapse (always focusing on the same position)
